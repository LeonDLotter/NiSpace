Reference Datasets
==================

.. important::

   **Reference data are not normative data.** The datasets below are third-party maps from
   other studies and other people: PET maps are group averages of usually small, selected
   samples with study-specific methods, and post-mortem data (gene expression, cell types,
   histology) come from one to a few donors. Every colocalization analysis nevertheless treats a
   reference map *as if* it represented the spatial distribution of that measure in the studied
   population. This assumption can rarely be tested and should be stated as a limitation in any
   study using these data. Describe each map by what it is (tracer and target, sample, source;
   see :func:`~nispace.datasets.fetch_map_info`) and avoid terms like "normative PET maps".
   See also the :doc:`concept notebook <nb_introduction/intro01_spatial_colocalizations>`.
